# AI Medical Diagnosis Database

## Project Description

This project provides the PostgreSQL database for an AI-Based Medical Diagnosis Assistant.

The database stores:

- User information
- Consultation records
- AI disease predictions
- AI-generated responses
- Specialist recommendations
- Medical reports
- Disease descriptions
- Disease precautions
- Symptom severity

The database is designed to work with the Backend API and the Machine Learning model.
