# 🩺 AI Medical Diagnosis Database

A PostgreSQL database module for the **AI-Based Medical Diagnosis Assistant**.

---

## 📌 Project Overview

This project is responsible for storing and managing all database-related information for the AI Medical Diagnosis Assistant.

The database stores:

- User information
- Consultation history
- AI disease predictions
- AI-generated medical responses
- Specialist recommendations
- Medical reports
- Disease descriptions
- Disease precautions
- Symptom severity data
